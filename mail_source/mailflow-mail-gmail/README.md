# Gmail Mail Source

Registers the mail source component id `gmail`. IMAP to imap.gmail.com:993 (SSL), SMTP via smtp.gmail.com:587 (STARTTLS). Options: `username`, `password` (**an app password, not your account password** — enable 2-Step Verification then create one under Google Account → Security → App passwords), `imap_folder` (default INBOX), `interval_seconds` (default 300), `limit` (default 20), `analyze_backlog` (default false). Native OAuth is planned; today the adapter uses IMAP with an app password.
